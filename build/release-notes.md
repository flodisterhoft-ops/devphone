# DevPhone 0.2.0

- Pin a DevPhone profile to the active Codex or Claude task, tab, or window; it hides when you switch away and returns in the same state when you come back.
- Run multiple named DevPhone profiles at once, each with isolated storage and its own preview session.
- Use the Android home-screen search bar as a Chrome address/search field, including pasted local or public URLs.
- Show phone clocks in 12-hour AM/PM format.
- Clear transient notifications reliably when DevPhone is minimized or hidden.
- Restore each profile's active browser, PWA, URL, rendering engine, and scroll position.
